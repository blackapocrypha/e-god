# E-God

#### 介绍
E-God即为eightGod，是一款根据公历日期进行八字排盘的简单工具。年月日时四柱配天干地支共八字，且字字有其阴阳，字字有其神韵，固称之为“八神”。

<br/><br/>

#### 软件架构
| 环境       | 版本    |
| ---------- | ------- |
| jdk        | >=17    |
| springboot | 3.3.3   |
| vue        | ^3.4.29 |

<br/><br/>

#### 启动教程

> 前端

1.  `npm install`
2.  `npm run dev`
3.  后台地址配置在`@/util/request.ts`的baseURL中

> 后端

1. 直接启动`DivinationApplication`，端口默认9369

<br/><br/>
